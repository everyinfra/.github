# EveryInfra 团队

EveryInfra 2024 年创立于加州 Santa Clara。团队 26 人，分布在 Santa Clara 和新加坡：三位创始人，加 23 位工程师和研究员。

## 创始人

### Echo · 创始人兼 CEO

- **毕业于：** 哥伦比亚大学
- **曾任职于：** Databricks
- **在 EveryInfra：** 在 Databricks 从 Delta Lake 事务日志做起，后来负责企业数据产品线。2024 年初在 Santa Clara 创立 EveryInfra：给开发者一个 Key，拿全世界的平台数据。

### Hacking · 主力工程师 · 数据平台

- **毕业于：** 哥伦比亚大学
- **曾任职于：** Amazon → Stripe
- **在 EveryInfra：** AWS 上做跟钱打交道的系统出身，Stripe 四年做幂等与 webhook 可靠性。在 EveryInfra 负责账本、计费和所有跟钱有关的管道。

### keuury · 主力工程师 · 平台覆盖

- **毕业于：** 哈佛大学
- **曾任职于：** Oracle → ByteDance
- **在 EveryInfra：** Oracle 两年数据集成，字节跳动四年短视频内容数据。在 EveryInfra 负责社媒与短视频平台的全部接入。
